# PCSO Lotto 6/42 analysis

Statistical findings from **919 unique** PCSO Lotto 6/42 draws (Aug 2020 – Jul 2026).

## Live page

**https://joboyx.github.io/pcso-lotto-642-analysis/**

## Headline findings

| Finding | Result |
| --- | --- |
| Draws with ≥1 consecutive number-line pair (`\|a−b\|=1`) | **58.2%** observed vs **55.7%** theory |
| Consecutive pairs as jackpot predictor | **No** — similar rates with/without winners |
| All 6 balls ≤31 (birthday range) | Jackpot hit **~41%** of those draws vs **14.5%** overall |
| Exact 6-number combo repeats across dates | **0** (expected ~0.08 in this sample) |
| Ball-frequency uniformity | Consistent with a fair draw |

Not betting advice — expected value of playing stays negative.

## Source

Analysis of a public draw-results inventory (duplicates on the same calendar date dropped). Combinatorics use exact `C(42,6)` enumeration where noted.
